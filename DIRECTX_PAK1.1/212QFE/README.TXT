               -----------------------------------------                
                Windows CE version 2.12 QFE Installation
               -----------------------------------------


Usage:
instrXXX.bat WINCEROOT
WINCEROOT = root path of your DXPAK 1.1 and Platform Builder 2.12 installation

Example:
instr4300 f:\WinCE212

Description:
Installs Windows CE 2.12 Core OS QFE's 1-7, 9-11.  Must be run from within the 212QFE folder.

instr4300.bat - installs MIPS QFE's
instsh4.bat - installs SH4 QFE's
instx86.bat - installs x86 QFE's
