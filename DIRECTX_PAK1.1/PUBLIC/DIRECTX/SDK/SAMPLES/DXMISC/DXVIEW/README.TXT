DirectX Caps Viewer
-------------------

The DirectX Caps Viewer tool enumerates devices and capabilities for all of
the supported components of DirectX.  For this release of the DXPAK,
information is displayed for the following:

    DirectDraw
        (display)
        Hardware Emulation Layer
    DirectSound Devices
    DirectSoundCapture Devices


User's Guide

Select items in the tree view. Information appears in the pane on the right.
You may select whether to display all items or only supported items by
selecting "View->Available caps only" or "View->All caps" options.

You may also print the capabilities tree to a text file, which by default
is written to \dxview.txt on the Windows CE device.
