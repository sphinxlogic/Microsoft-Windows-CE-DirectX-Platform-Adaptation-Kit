Description
===========
  This is a slightly modified version of the IESamples web browser hosting
  application.

User's Guide
============
  If IESample is enabled in the maxdx image (set IMGIESAMPLE=1) there is a
  shortcut for IESample placed on the desktop, double click on the icon to
  run IESample.

Programming Notes
=================
  The changes made from the standard IESample are documented in the wmphlpr
  sample readme.txt located in %_WINCEROOT%\public\maxdx\oak\wmphlpr.
